# Casino Yessir Addiction

Browser-based casino-style simulator. All play is virtual; no real-money deposits, purchases, or cash-outs.

- `index.html` — original game.
- `safe-upgrades.js` — blackjack practice, scripted reel preview, and performance diagnostics.

The Pages workflow deploys the repository root. In Settings → Pages, select **GitHub Actions**. GitHub Free Pages requires a public repository.
